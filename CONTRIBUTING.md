# Contributing to Ghost Empire

Thanks for your interest in a **Ghost Empire** project! 👻🔴⚫

- 💬 **Questions & coordination:** [Discord](https://discord.gg/Egf88V9UdH)
- 🐛 **Bugs / features:** open an issue with clear steps to reproduce and your environment (server/runtime version, OS, logs).
- 🔧 **Pull requests:** keep them focused, describe the change, and make sure the build and tests pass.
- 🔒 **Security issues:** see [SECURITY.md](SECURITY.md) — report privately, never via public issues.

> Some repositories are **proprietary** or **downstream forks** — check each repository's `LICENSE` before contributing.

These defaults apply across all Ghost Empire repositories unless a repository provides its own contributing guide.

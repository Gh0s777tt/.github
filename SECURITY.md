# Security Policy

Thanks for helping keep **Ghost Empire** projects safe. 👻🔴⚫

## Reporting a vulnerability

Please report security issues **privately** — do **not** open a public issue.

- 📧 **Email:** ghostt77@empire-forge.com
- 💬 **Discord:** [discord.gg/Egf88V9UdH](https://discord.gg/Egf88V9UdH) (DM a maintainer)

Include where possible: affected project/version, impact, and clear reproduction steps.

## What to expect

- Acknowledgement within a few days.
- Updates as we investigate and work on a fix.
- Credit for the report once the issue is resolved (if you'd like).

This policy applies across all Ghost Empire repositories unless a repository provides its own `SECURITY.md`.
